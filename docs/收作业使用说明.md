# 收作业使用说明

完整运行步骤见 [使用指南](使用指南.md)。

统计采用跨周累计方式：每个学生一行，第一列为姓名，第二列为学号，后续列为第1周、第2周等。

仅收取和统计学号大于 `2600015446` 的学生，不含该学号本身；网页使用相同范围。

`--assignment 3` 仅限制本次下载第三周附件，不限制 Excel 的历史周次。全学期始终使用同一个输出目录 `作业收集_2026秋`。

同一学号、同一周只采用最后一次合法 PDF 提交，按邮件 Date 时间排序；时间相同时以数字 UID 排序，缺少或无效时间的记录排在有效时间之前，再以 UID 和记录键稳定排序。后来的空邮件、非 PDF、已确认损坏的 PDF 不覆盖之前的合法提交。普通 PDF 检查文件头和结束标记；超大附件尚未下载成功时仍作为候选，打钩并记录异常，确认不是 PDF 后才回退到之前的合法版本。

选中邮件里的多份 PDF 全部保留。ZIP 只从该次提交的收取记录取文件，不再扫描整个目录；历史附件留在本地备查，不进入 ZIP。若最新合法提交尚未下载到文件，ZIP 不混入旧版本；没有任何可打包文件时生成空 ZIP，避免旧包被误用。Excel“邮件明细”的“采用情况”列标明当前采用、历史提交或不符合 PDF 收取要求。`--pack-only`、超大附件重试及补录后打包也使用相同选择规则。

自动读取项目根目录下唯一的“选课名单” .xls/.xlsx 文件，也可用 `--roster` 指定。名单表头须包含“学号”“姓名”。支持旧版 .xls 名单。

本地 `收取记录.json` 是累计记录；Excel 每次重新生成，手动编辑不会保留。运行前请关闭 Excel。

## QQ 邮箱超大附件

收取命令不变。脚本自动识别邮件正文中的 QQ 文件中转站链接，尝试通过 HTTP 跳转、静态下载页面取得 PDF，分块写入临时文件。下载成功并通过文件头、结束标记及服务器声明的长度检查后，才归档到学生目录并更新记录、ZIP、Excel 和网页。不增加第三方依赖。

```powershell
. .\邮箱配置.local.ps1
python scripts/收作业.py --since 2026-09-01 --assignment 3 --output 作业收集_2026秋
```

默认单次网络读写超时为 120 秒（不是整个文件的下载时限），最多尝试 3 次，单个文件上限 10240 MB。可用 `--large-timeout 300 --large-max-mb 20480` 调整。中断后从头重试，暂不支持断点续传。已完成且通过本地检查的超大附件会跳过下载。

超大附件与普通附件使用相同的归档格式：`邮件标识_附件序号_原始文件名.pdf`。新版 QQ 附件名从文件信息中读取，其他下载优先读取响应中的文件名，补录使用所选 PDF 的文件名。序号保存到记录中，重复运行保持不变；ZIP 打包时照常在前面加上 `学号_姓名_`，便于批改后返还。

遇到网页登录、验证码、动态脚本页面、无法识别的链接或非 PDF 文件时，不会把网页保存成 PDF。原因和任务编号写入本地 `超大附件待处理.txt` 及 Excel 的“邮件明细 / 超大附件待处理”列。链接失效时需要发送者重新提供有效附件。

仅重试已记录的超大附件，不重新连接邮箱：

```powershell
python scripts/收作业.py --retry-large --assignment 3 --output 作业收集_2026秋
```

如果自动下载失败，在 QQ 邮箱网页打开原邮件并下载 PDF，然后从待处理清单复制完整任务编号进行补录：

```powershell
python scripts/收作业.py --import-large "清单中的任务编号" "C:\Users\10338\Downloads\作业.pdf" --output 作业收集_2026秋
```

补录会复制文件到对应周次和学生目录，并更新收取记录、该周 ZIP、累计 Excel 和网页；原下载文件保留。使用与收取时相同的 `--output`，自定义网页目录时同时传入原来的 `--web-output`。后续重新收取邮件会保留补录结果。

提交认定与下载结果分开：只有主题符合现有支持格式、且学号和周次与记录一致的作业邮件才计为“已交”，无需附件或成功下载。不通过姓名猜测、截取主题片段或发件人推断提交。邮件明细仍保留“超大附件待下载”“无PDF附件”等收取状态，附件问题不影响打钩。主题格式错误的邮件需核对；原有历史已交标记继续保留。

每次导出同步生成本地 `收取异常记录.txt` 和 Excel 的“收取异常”工作表，列出周次、学号、姓名、提交认定、异常原因、邮件主题和邮件时间。异常清单随当前状态更新，解决后不再列出；不会发布到查询网页。

下载入口和任务记录只保存在本地输出目录，不写入公开查询网页。支持 QQ 邮箱旧版 `ftn` 下载入口、新版 `wx.mail.qq.com/ftn/download` 及中转站文件服务器。新版链接按官方分享页流程查询文件信息，再请求实际文件，并保留跳转设置的临时 Cookie（仅在内存中保存）；不需要使用 IMAP 授权码登录网页。成功下载后还会核对 QQ 返回的文件大小和 SHA-1（如果提供），防止截断或错误内容入库。

不执行网页 JavaScript，不支持微云、百度网盘或自动解压 ZIP。分享接口明确拒绝访问时会保留返回码供排查，不能据此直接断言已过期；需要交互验证的链接仍需网页下载后补录。ZIP 请先下载并解压其中的 PDF，再使用 `--import-large` 补录。HTTP 400 曾由缺少 QQ 跳转响应中的 `mail5k` Cookie 导致，现已通过临时 Cookie 会话处理。

指定 `--assignment` 时先读取邮件主题，只获取对应周次的邮件正文与附件，其他周次不新增记录。兼容“第四周作业 姓名 学号”和“第四周高数作业+学号+姓名”格式；无法解析学生信息的本周邮件仍列为“主题格式错误”。
